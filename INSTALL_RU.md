# Установка Forest Studio 2.0 v0.4.6 Beta (полный комплект)

Это **полный комплект скриптов**, включая `xrTools.ObjectImport.ms` и `forest_thm_cache.py`. Скачивать отдельный MAXScript-импортёр не требуется. Движок, исходники WPF и скрипты из подтверждённой рабочей v0.4.6 не переписывались.

## Требования

- **Windows 10/11**, **Autodesk 3ds Max 2024**.
- **Windows PowerShell 5.1** и установленный **.NET Framework 4.x с WPF** — для сборки интерфейса.
- **Python 3** в PATH для функции создания PNG-миниатюр из `.thm`; сторонние Python-модули не требуются.
- Установленный **X-Ray SDK** с `rawdata\objects\trees` и `gamedata\textures`. Модели и DDS-текстуры в архив не входят.

## Установка в три шага

1. Распакуйте **содержимое** ZIP, например в `C:\Projects\ForestStudio\`. Все `.ms`, `.cs`, `.cmd`, `.ps1` и `.py` остаются вместе. **Не копируйте файлы в `Program Files\Autodesk`.**
2. Закройте 3ds Max, запустите `C:\Projects\ForestStudio\Build_WPF.cmd`. Дождитесь строки `OK: ForestStudio.Wpf.dll created`. DLL появится рядом. Если компилятор выдал ошибку, пришлите полный вывод.
3. Запустите 3ds Max 2024 → **Scripting → Run Script** → `C:\Projects\ForestStudio\Forest_Studio_v0_4.ms`.

В **Проекте** укажите корень SDK, например `D:\ixray\sdk`. Программа рассчитывает пути автоматически:

- `.object` и объектные `.thm` → `D:\ixray\sdk\rawdata\objects`;
- игровые DDS-текстуры → `D:\ixray\sdk\gamedata\textures`;
- библиотека — все `.object` в `rawdata\objects\trees` и вложенных папках.

Для THM-иконок: **Библиотека → THM → PNG**. Для обновления изображений воспользуйтесь кнопкой очистки кэша, затем снова создайте PNG.

## При обновлении

Сначала сохраните старую папку Forest Studio и пользовательские пресеты. В новый каталог можно распаковать комплект независимо от старого. После пересборки DLL **полностью перезапускайте 3ds Max**, чтобы приложение не использовало предыдущую DLL в памяти.

## Что НЕ включено

Системный 3ds Max, X-Ray SDK, файлы моделей `.object`, SDK `.thm`, DDS, текстуры, `scene_object.part`, пользовательские `.max`, маски и пресеты. Это рабочая программа, а не сборка игрового контента. Приложение не устанавливается в папку Autodesk и не требует администратора.

## Первый запуск

Проверьте библиотеку, поиск, RGB/Alpha-маску, группу, импорт/LOD; генерацию и экспорт первый раз запускайте **только на копии сцены и `scene_object.part`**. Версия публичная Beta и не проверена на каждой конфигурации Windows/SDK.
