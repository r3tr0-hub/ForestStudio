# Forest Studio 2.0 — v0.4.6 Beta

**Forest Studio** — инструмент расстановки деревьев, кустарников и других объектов X-Ray SDK для **Autodesk 3ds Max 2024**. Генератор работает с пользовательской картой `*_forest.tga`, каталогом `.object` из SDK и экспортом размещений в `scene_object.part`.

> Статус: **публичный релиз-кандидат v0.4.6 Beta**. Автор подтвердил работу v0.4.6 на своей установке Max 2024. Автоматизированные Windows/WPF-тесты и проверка на других версиях Max не проводились. Это не официальный продукт Autodesk или GSC Game World.

## Возможности

- WPF-интерфейс внутри 3ds Max: **Проект / Библиотека / Маска / Расстановка / Экспорт SDK**.
- Автоматическая библиотека `.object` со всеми подпапками `SDK\rawdata\objects\trees`; фильтрация по реальным папкам и поиск по именам.
- Миниатюры из `.thm` через локальный PNG-кэш; очистка и регенерация кэша.
- Маска `*_forest.tga`: RGB-группы, альфа-канал плотности, пипетка цвета, поиск доминантных цветов с настройкой допуска.
- Плотность в объектах/га; минимальная дистанция; масштаб, наклон, ориентация, случайность, seed.
- Вес появления каждой модели **внутри группы** (относительный, не абсолютная доля).
- Автосохранение настроек, пресеты составов и параметров групп.
- Импорт `.object` посредством **включённого в комплект** `xrTools.ObjectImport.ms`, подготовка LOD.
- Экспорт ссылок `ref_name` и трансформаций в `.part` с резервной копией; префикс `test_...`.
- Очистка объектов, помеченных `forest_generated`, с подтверждением и возможностью Undo в 3ds Max.

## Требования

- Windows 10/11, Autodesk 3ds Max **2024** (проверенная среда).
- Windows PowerShell 5.1 и установленный .NET Framework с WPF (обычно уже есть в системе).
- Python 3 для конвертации THM в PNG (путь/настройки смотрите в интерфейсе; сама C#-оболочка собирается без Python).
- Установленный **X-Ray SDK** с папками `rawdata\objects` и `gamedata\textures`.
- **Импортёр `xrTools.ObjectImport.ms` входит в ZIP**. Использует совместимую с X-Ray SDK локальную копию; отдельная установка импортёра не нужна.

## Установка

1. Загрузите файл `ForestStudio_v0.4.6-beta_complete.zip` из вкладки **Releases**, а не автоматический исходный ZIP GitHub.
2. Распакуйте в произвольную папку, например `C:\Projects\ForestStudio`.
3. Проверьте, что `xrTools.ObjectImport.ms` уже находится в папке — он включён в архив. Дополнительная установка импортёра не требуется.
4. Закройте 3ds Max. Запустите **`Build_WPF.cmd`**, дождитесь сообщения `OK: ForestStudio.Wpf.dll created`.
5. Запустите 3ds Max 2024: **Scripting → Run Script → `Forest_Studio_v0_4.ms`**.
6. На вкладке «Проект» задайте только **корневую папку SDK**, например `D:\ixray\sdk`. Пути объектов (`rawdata\objects`) и DDS (`gamedata\textures`) вычисляются автоматически.
7. Для просмотра миниатюр используйте команду **THM → PNG** на вкладке «Библиотека».

При обновлении сначала сохраните копию рабочей папки и пресетов. При изменении `.cs` обязательно пересоберите DLL и **полностью перезапустите Max** перед тестом.

## Минимальная последовательность работы

1. В «Проекте» укажите террейн, `*_forest.tga` и SDK.
2. В «Маске» проверьте RGB/Alpha, при необходимости найдите цвета и создайте группы.
3. В «Библиотеке» добавьте `.object` в группы.
4. В «Расстановке» задайте плотность, дистанцию, масштаб и веса, сгенерируйте на тестовой сцене.
5. Проверьте сцену, затем экспортируйте **в копию** `scene_object.part` на вкладке «Экспорт SDK».

## Ограничения

- **Структуры, кластеры/поляны, редактор маски и фильтры по крутизне склона** ещё не реализованы. Это планируемые функции, см. [`docs/ROADMAP_STRUCTURE.md`](docs/ROADMAP_STRUCTURE.md).
- Каталог содержит все обнаруженные `.object` из `trees` SDK, но интерфейс одновременно может отображать ограниченное количество карточек; поиск выполняется по всему каталогу.
- Анализ цвета маски объединяет близкие оттенки, а текущий алгоритм фактической посадки использует более узкий RGB-допуск: на очень плавных градиентах возможны пробелы.
- В распространяемый пакет **не входят** файлы SDK `.object`, `.thm`, `.dds`, игровые ассеты, созданные пользователем пресеты и сцены.
- DLL не включена: WPF исходник собирается локально на Windows.

## Обратная связь

При ошибке прикладывайте версию 3ds Max, версию Forest Studio, вывод `Build_WPF.cmd` или MAXScript Listener, шаги воспроизведения. Не публикуйте личные SDK-файлы без прав на их распространение.

### Полный комплект

Скачивайте файл с суффиксом `_complete.zip`: он включает `xrTools.ObjectImport.ms` рядом со скриптом запуска. Готовая WPF DLL не поставляется и собирается на вашем Windows-компьютере через `Build_WPF.cmd`.
