# Forest Studio 2.0 — генератор леса для 3ds Max + X-Ray SDK [v0.4.6 Beta]

**Автор:** r3tr0-hub / Retr_0  
**Лицензия:** MIT  
**Для:** Windows, 3ds Max 2024, X-Ray SDK

Forest Studio позволяет массово расставлять деревья и объекты окружения по
`*_forest.tga` (цвета RGB задают группы, альфа управляет плотностью) и экспортировать
размещения в `scene_object.part`.

### Возможности

- Тёмный WPF-интерфейс с пятью разделами: Проект, Библиотека, Маска, Расстановка, Экспорт SDK.
- Каталог моделей `.object` из **всех** папок `SDK\rawdata\objects\trees`, поиск и THM-превью.
- Пипетка RGB, автоматический поиск основных цветов маски, переключение RGB/Alpha.
- Плотность (шт./га), дистанция, поворот, масштаб, нормаль поверхности, относительные веса моделей.
- Пресеты групп и автоматическое сохранение.
- Импорт `.object` с включённым `xrTools.ObjectImport.ms`, LOD и экспорт в `.part`.
- Удаление только сгенерированных объектов и резервные копии перед экспортом.

### Установка

Распаковать ZIP, выполнить `Build_WPF.cmd`, в 3ds Max выбрать
**Scripting → Run Script → `Forest_Studio_v0_4.ms`**. Указать корень SDK.
Для THM-превью нужен Python 3. Программа не включает игровые ресурсы.

### Статус и планы

**Beta**, основной функционал проверен автором на 3ds Max 2024. Для баг-репортов
прикладывайте Max Listener и шаги воспроизведения. Первый экспорт делайте на копии `.part`.

В планах: структуры из набора `.object`, естественные рощи/поляны, привязка
к крутизне склонов и редактирование маски.
