# Forest Studio 2.0 — v0.4.6 Beta

Первый публичный бета-релиз генератора леса для **3ds Max 2024 + X-Ray SDK**.

**Возможности:** WPF-интерфейс (Проект / Библиотека / Маска / Расстановка / Экспорт SDK),
рекурсивный каталог `.object` из `rawdata\objects\trees`, THM-превью, посадка по
RGB и Alpha `*_forest.tga`, плотность, дистанции, вес каждой модели, автосохранение
и пресеты групп, импортер X-Ray, LOD, экспорт в `.part` с резервным копированием,
очистка только созданных объектов.

**В архиве `ForestStudio_v0.4.6-beta_COMPLETE_MIT.zip`:** исходники MAXScript/WPF,
`Build_WPF.cmd`/`.ps1`, THM-декодер и X-Ray импортёр Dan-Stash. **DLL собирается
на компьютере пользователя**. Игровые ассеты SDK не включены.

**Установка:** распаковать, запустить `Build_WPF.cmd`, затем выполнить
`Forest_Studio_v0_4.ms` в 3ds Max через Scripting → Run Script.
Корень SDK указывается один раз. Для миниатюр нужен Python 3.

**Лицензия:** Forest Studio — MIT © 2026 r3tr0-hub;
сторонние компоненты — см. [`THIRD_PARTY.md`](../THIRD_PARTY.md).

**Это Beta:** начните с копии `.max` и `scene_object.part`; работа на разных системах
не проверена. Структуры, кластеры, уклоны террейна и редактор маски — в планах.

Скачивать именно прикреплённый ZIP из **Releases**, а не исходный ZIP GitHub.
