# Скриншоты для публичной темы

Прикрепите скриншоты **реальной v0.4.6 WPF внутри 3ds Max 2024**, не HTML-концепта и не будущих функций:

1. «Проект»: корень SDK, выбранный террейн/маска.
2. «Библиотека»: реальное дерево папок `trees`, карточки из THM.
3. «Маска»: RGB-изображение и включённый Alpha.
4. «Расстановка»: группы, веса моделей, настройки расстояния/плотности.
5. «Экспорт SDK»: экран выбора `.part` и успешный результат на **тестовом** файле.

Не показывайте полные локальные пути, личные файлы и чужие ресурсы без разрешения. В скриншотах замазывайте персональные названия проектов, если необходимо.
