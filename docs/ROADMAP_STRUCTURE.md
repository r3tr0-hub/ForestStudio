# Roadmap: природная генерация, структуры, анализ рельефа, редактор масок

План, **не включённый в текущий релиз v0.4.6**. Полная спецификация находится в отдельном документе `Forest_Studio_Structures_Design_RU.md` в публикационном комплекте.

## Направления

- **Естественные скопления:** кластеры деревьев, рощи и поляны поверх плотности/Alpha с сохранением среднего числа объектов и воспроизводимым Seed.
- **Рельеф:** допустимый диапазон высот, уклон, ориентация склонов и типы выравнивания по нормали.
- **Маска:** неразрушающее рисование по RGB/Alpha, слои, Undo, подсветка зон, сохранение `*_forest.tga` с резервными копиями.
- **Структуры:** отдельная вкладка для сохранения компактных локальных композиций в JSON на диске. В JSON — только ссылки SDK на `.object`, относительные трансформации и правила привязки к рельефу; 3D-модели не копируются.

Следующий этап реализации: контейнер формата структур, UI-библиотека шаблонов и захват выделения из сцены, затем размещение экземпляров по маске/террейну.
